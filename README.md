# DON ENTERPRISES website

Responsive single-page school website built with HTML, CSS and JavaScript.

## Included files
- `index.html` — website.
- `robots.txt` — permits search engine crawling.
- `sitemap.xml` — starter sitemap.
- `README.md` — instructions.

## Before publishing
1. Replace `https://YOUR-DOMAIN.vercel.app/` in the canonical link with your actual live URL.
2. Replace `YOUR-DOMAIN` in `robots.txt` and `sitemap.xml` with your actual Vercel domain.
3. Replace sample email, phone number and address with the school's official details.
4. Login/Register is a demo only. Real accounts require a secure backend and database.
5. Photos are loaded from Unsplash and need an internet connection.

## Google Search Console
Download Google's exact HTML verification file and place it in the same published root folder as `index.html`, without renaming or editing it. After redeploying, open `https://YOUR-DOMAIN.vercel.app/EXACT-GOOGLE-FILENAME.html` to check it loads, then click Verify in Search Console.

After verification, use URL Inspection to request indexing and submit `https://YOUR-DOMAIN.vercel.app/sitemap.xml` under Sitemaps. Indexing can take days or weeks and is not guaranteed.
